# Cool Assist Ai для Android

Личная мобильная версия: звук записывается микрофоном телефона, распознавание речи и резюме выполняет OpenAI. Локальных AI-моделей и отдельного сервера нет. Минимальная версия — Android 10. Целевое устройство пользователя — Pixel 8 с Android 17 Beta; Результаты проверок текущего выпуска — в RELEASE-2.0.0.md.

## Первый запуск

1. Установите `CoolAssistAi-Android-2.0.0.apk`. При установке из файла Android может попросить разрешить установку для выбранного файлового менеджера/браузера.
2. Откройте **Настройки**, вставьте свой **OpenAI API key**, нажмите **Проверить и сохранить**. По умолчанию: `gpt-4o-transcribe` для речи, `gpt-5.4` для резюме. Модели можно заменить; ключ должен иметь доступ к audio/transcriptions и responses. Если ключ ограничен и не разрешает просмотр models, используйте **Сохранить настройки**, затем проверьте работу на короткой встрече.
3. В библиотеке нажмите **Записать встречу**. Разрешите микрофон; уведомление позволяет остановить запись при свёрнутом приложении. Предупредите участников о записи.
4. На экране записи видно настоящий уровень микрофона. Волна замирает на паузе; «Отметить важное» сохраняет временную отметку в заметках. Откройте вкладку **Текст**. Новые аудиофрагменты поступают на распознавание фрагментами по 6–14 секунд; фактическая задержка зависит от сети и API. Пауза приостанавливает микрофон. После остановки обрабатываются оставшиеся фрагменты и создаётся резюме.
5. В резюме нажмите время под тематическим пунктом или действием, чтобы перейти к исходной реплике. Можно добавить выбранное действие в задачи. Личные заметки сохраняются отдельно. Кнопки скачивания и отправки экспортируют **Markdown с резюме, задачами, заметками и полной хронологической расшифровкой**.

Во время обработки можно открыть другую встречу или начать новую запись. Меню встречи позволяет приостановить обработку и затем повторить её с сохранённого места. Переходы учитывают системное отключение анимаций. API оплачивается отдельно от подписки ChatGPT. Приложение не запрашивает и не получает ваш ключ из macOS-версии.

## Хранение и восстановление

- Аудио записывается непрерывно в PCM16 mono 16 kHz, по 6–14 секунд на WAV-фрагмент, с предпочтением границ на коротких паузах речи. Примерно 115 МБ на час, около 346 МБ на 3 часа (без учёта файловой системы). Вся встреча не загружается в оперативную память.
- Незавершённый фрагмент регулярно сбрасывается на диск. После сбоя приложение восстанавливает доступные фрагменты и помечает запись прерванной; микрофон самостоятельно не включается. Последние несохранённые данные при жёстком сбое могут быть потеряны.
- Без сети звук сохраняется локально. Очередь возобновляет обработку при доступной сети. Ошибки ключа/баланса требуют исправить настройки и повторить обработку; автоматические попытки ограничены.
- Во время записи распознавание работает внутри сервиса записи, с отдельным каналом выполнения запросов. WorkManager хранит очередь для восстановления и фоновой обработки. Android может отложить фоновые задания после завершения записи.
- Ключ шифруется AES-GCM ключом Android Keystore. Он не входит в APK, экспорт, логи или резервное копирование. Это личный BYOK-клиент; владельцу устройства следует защищать телефон и использовать отдельный API-ключ с лимитом расходов.
- Записи и SQLite-библиотека находятся в приватной папке приложения. Облачное резервное копирование/перенос приложения отключены, чтобы ключ и встречи не попадали в автоматическую копию. Перед удалением приложения экспортируйте нужные протоколы. Удаление встречи внутри приложения требует подтверждения.

## Границы этой версии

Приложение предназначено для очных встреч и звука вокруг телефона. Универсальный захват звонков Meet/Zoom/WhatsApp, телефонной линии и экрана не реализован: Android ограничивает доступ к аудио других приложений, особенно VOICE_COMMUNICATION. Если встреча идёт на компьютере, телефон может записывать её микрофоном при достаточной слышимости.

Распознавание идёт фрагментами во время встречи, а не отдельным проходом после остановки. Энергетический анализ предпочитает паузы речи для границ фрагментов и никогда не удаляет тихий звук; при непрерывной речи фрагмент ограничен 14 секундами. Предыдущий распознанный текст передаётся как контекст следующего фрагмента. В настройках можно выбрать более экономную модель `gpt-4o-mini-transcribe` или ввести поддерживаемую модель вручную. Уже сохранённая модель не меняется при обновлении. Это не пословный поток Realtime API. Автоматическое определение личности говорящих и интонации не заявляется. Полная расшифровка сохраняется отдельно от сокращённого резюме. AI может ошибаться; ориентировочные сроки и предложения должны оставаться таковыми.

В этой версии нет синхронизации с Mac, импорта сторонних аудиофайлов и резервного экспорта исходного аудио. Удаление приложения удалит локальную библиотеку; экспорт Markdown сохраняет текст.

## Сборка

Нужны JDK 17, Android SDK platform 35/build-tools 35.0.0. Gradle 8.11.1 закреплён wrapper и проверкой SHA-256. AGP 8.9.2 / Kotlin 2.1.20. Исходники Android находятся в отдельной папке и не меняют macOS-приложение.

```bash
export JAVA_HOME=/path/to/jdk17
export ANDROID_HOME=/path/to/android-sdk
cd android
./gradlew :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
# С подключённым отдельным тестовым устройством/эмулятором:
./gradlew :app:connectedDebugAndroidTest
./build-release.sh
```

Скрипт выпуска для macOS создаёт личный ключ подписи в игнорируемой `.tools/android/signing/` и хранит его пароль в macOS Keychain (`cc.idomus.meetprotocol.android.release-signing`). При следующих сборках используется та же подпись. Сохраните защищённую копию ключа и доступ к этой записи Keychain: без исходного ключа нельзя установить обновление поверх существующей версии. Никакие ключи подписи и пароли не включаются в исходный проект или APK. `MEET_ANDROID_SIGNING_DIR` позволяет выбрать защищённую папку подписи.

Идентификатор пакета `cc.idomus.meetprotocol` и прежняя подпись сохраняются для обновления существующей установки без удаления данных. Не удаляйте старую версию перед установкой обновления.

APK предназначен для установки пользователем из файла. Публикация в Google Play не выполнялась.
