# Cool Assist Ai 2.0.0

## Изменения

- Новое название и логотип, спокойный тёмно-серый интерфейс с акцентом `#d60000`. Анимация записи показывает уровень входящего звука; поддерживается уменьшение движения.
- На macOS сохранены локальные Whisper/Qwen, запись только микрофона без разрешения на экран, компактный виджет и совместимость с каталогом встреч прежнего приложения.
- Windows/Linux: локальный Whisper Small Q5 и Qwen3 4B Q4, загрузка моделей из настроек с проверкой SHA-256, продолжением загрузки и отменой. После установки моделей интернет для локального AI не требуется. OpenAI остаётся отдельным режимом с собственным ключом.
- Android использует облачное распознавание и резюме, как предусмотрено для телефонной версии. Запись сохраняется локально и может обрабатываться после восстановления сети.
- Резюме структурировано по темам, решениям и поручениям. Проверяются ссылки и точные цитаты исходных реплик, сохраняются оговорки об условиях и неподтверждённых сроках. Полный текст входит в Markdown.
- Обработка одной встречи не блокирует просмотр другой. Исправлены продолжение очереди Android, быстрые нажатия паузы/остановки, обновление задач и сохранение черновика заметок на ПК.
- При зависании Metal на Mac предусмотрена ограниченная повторная попытка распознавания на CPU. Отмена операции не запускает повторное распознавание.

## Границы проверки

- Физический Pixel с Android beta, реальные Windows/Linux устройства и оплата запросов OpenAI в этом прогоне не проверялись. Установка и работа микрофона/loopback на конкретном ПК требуют отдельной приёмки.
- Визуальные Android UI tests прошли до окончательной замены чёрного фона графитовым. При завершающем запуске release APK под высокой нагрузкой хоста возник системный Android System UI ANR; это не считается чистой визуальной приёмкой release на устройстве. Финальный цветовой APK прошёл сборку, unit tests, lint и проверку подписи, без нового запуска AVD.
- Desktop UI проверялся на macOS в тестовом Electron. Искусственный вход этого UI-прогона дал тишину; проверка жизненного цикла записи не доказывает захват физического микрофона Windows/Linux. Реальный локальный адаптер ASR отдельно проверен на публичном WAV.
- Ускоренный трёхчасовой тест не заменяет физическую непрерывную трёхчасовую запись. Качество произвольной речи, различение говорящих, имена и смысл выводов не могут гарантироваться безошибочными.
- macOS-приложение подписано постоянной личной identity для сохранения совместимости, но не нотариализовано Apple; PKG не подписан Developer ID Installer. Windows EXE не имеет Authenticode-подписи. Для доверенного массового распространения нужны соответствующие сертификаты владельца.
- Модели CPU на ПК расходуют несколько гигабайт RAM; скорость зависит от оборудования и конкурирующей нагрузки. Автоматического перехода из локального режима в облако нет.
- Точная цитата подтверждает происхождение текста, но не гарантирует правильную интерпретацию. В тесте Qwen мог предложить уточнение бюджета без прямого поручения; предлагаемые задачи требуют проверки и ручного добавления пользователем.

## Обновление и данные

Внутренние идентификаторы macOS и Android сохранены. Удаление приложения или обновление не должны использоваться как способ очистки встреч; удаляйте ненужные записи через интерфейс. Windows/Linux используют собственный каталог данных Electron. Межплатформенной синхронизации нет.

Установщики и контрольные суммы создаются в `dist/` и не добавляются в исходный Git-репозиторий. Инструкции сборки и настройки находятся в [README.md](README.md).
